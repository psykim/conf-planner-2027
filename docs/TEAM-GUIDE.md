# 2027 학회 플래너 — 팀원 접속 안내

## 주소
https://psykim.github.io/conf-planner-2027/

컴퓨터·휴대폰 브라우저 어디서든 열립니다. 앱 설치나 Claude 계정은 필요 없습니다.

## 로그인 (처음 한 번만)
1. 위 주소를 열면 로그인 화면이 나옵니다.
2. **팀에 등록된 본인 이메일**을 입력하고 「로그인 링크 받기」를 누릅니다.
3. 이메일로 도착한 「Your Magic Link」 메일의 **Log In 링크를 누르면** 바로 접속됩니다.
   (몇 분 내 도착 — 안 보이면 스팸함 확인)
4. 한 번 로그인하면 같은 브라우저에서는 계속 로그인 상태가 유지됩니다.

- "팀에 등록되지 않은 이메일입니다"가 나오면 → 김기웅 교수님께 등록을 요청하세요.
- 로그인 링크는 **링크를 연 브라우저**로 로그인됩니다. 휴대폰에서 쓰려면 휴대폰에서
  이메일을 여세요.

## 사용법
- 학회 이름을 누르면 상세 팝업이 열립니다.
- 팝업에서 **참가 여부**(참가/미정/불참)를 정하고, 참가로 정하면 아래 5개 섹션이 열립니다:
  ① 참가자(이름·이메일) → ② 참가신청(등록 상태·초록) → ③ 출장신청(병원 신청 기간)
  → ④ 항공(출국·귀국편) → ⑤ 숙소(구글맵 링크 자동 생성)
- 입력하면 **다른 팀원 화면에 몇 초 안에 자동 반영**됩니다.
- ④ 항공을 저장하면 ③ 출장신청 기간이 비어 있을 때 출국·귀국일로 자동 입력됩니다.
- 초록 제목을 저장할 때는 본인 확인용으로 **본인 이메일**을 한 번 입력합니다.
- 화면 위 탭으로 **🗓 학회 플래너**(타임라인·마감·전략 메모)와 **📋 관리카드**를 오갑니다.
- 참가로 정한 학회는 **📋 관리카드** 탭에 자동으로 카드가 생깁니다(탭 옆 숫자 = 카드 수) —
  학회 정보, 주요 일정(초록·등록 마감과 팀원 출장·출국·귀국을 날짜순으로, D-day 표시),
  참가자별 준비 현황(등록·초록·출장·항공·숙소 5가지)을 한눈에 봅니다. 카드를 누르면 **학회별 상세 페이지**가 열립니다 — 공식 사이트에서 조사한 준비 기한(확정·예상·미공지),
  등록비, 초록·발표 규정, 출입국(전자여행허가 등)·교통·숙소, 지원·수상, 참석 팁과 출처가 정리돼 있고,
  '참가 정보 편집' 단추로 기존 입력 팝업을 엽니다.
  주소 끝에 `#cards`를 붙이면 관리카드 탭으로 바로 열리고, 마지막으로 본 탭은 브라우저가 기억합니다.
- ★(관심)·필터·검색은 자유롭게 — ★는 본인 브라우저에만 저장됩니다.

## 관리자용 (김기웅 교수)
- 팀원 추가·제거: Claude에게 "OOO(이메일)을 팀에 추가해줘"라고 지시하면 됩니다.
  (Supabase `conf_allowed_emails` 테이블 관리)
